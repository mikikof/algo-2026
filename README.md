# algo-2026

平成国際大学 情報デザイン学部「アルゴリズムとデータ構造」（2026 年度後期）で、
受講している方が手元の端末から開く演習です。

## これは何か

裏向きのカードを 1 枚ずつめくって目的の数を探し、**めくった回数（手数）**を数えます。
決められた手数の中で解けると、提出用のコードが出ます。

スマートフォンで開いて、ホーム画面に追加すると、アプリと同じように全画面で開きます。
一度開いたあとは、通信が無いところでも動きます。

## 置いてあるもの

| | |
| --- | --- |
| `index.html` | 演習。第 2 回「探す」（線形探索と二分探索） |
| `sw.js` ／ `manifest.webmanifest` ／ `icon-*.png` | ホーム画面に入れて、通信が無くても動かすためのもの |

回が進むごとに増えます。
