# algo-2026

平成国際大学 情報デザイン学部「アルゴリズムとデータ構造」（2026 年度後期）で、
受講している方が手元の端末から開く演習です。

**https://mikikof.github.io/algo-2026/**

## これは何か

裏向きのカードを 1 枚ずつめくって目的の数を探し、**めくった回数（手数）**を数えます。
カードは 8 枚から始まり、16 枚、32 枚と増えます。決められた手数の中で解いてください。

流れは 3 つです。

1. **解く** … 6 問。列が倍になる手前で、「半分にしていくと何回で 1 枚になるか」を答えます
2. **まとめの問題** … 選択式が 4 問。授業で扱った内容から出ます
3. **出す** … 通ると、記録はボタンを押さずに送られます。うまく送れないときのために、
   控えのコードも表示できます

まちがえても、**その問だけ**引き直します。1 問目には戻りません。

## 開き方

ブラウザで上の住所を開くだけです。入れるものはありません。

**ホーム画面に追加すると、アプリと同じように全画面で開きます。**

| | |
| --- | --- |
| iPhone / iPad（Safari） | 下の「共有」→ **ホーム画面に追加** |
| Android（Chrome） | 右上の「︙」→ **ホーム画面に追加** |

一度開いたあとは、**通信が無いところでも解けます**。
解き終わったぶんは、つながったときに送られます。

## 置いてあるもの

| | |
